# Product Roadmap

날짜보다 의존성과 검증 순서로 관리한다.

## Phase 1 — 기획 기준 확립

- 스쿼드별 소유권과 AI 역할 확정
- 서비스명 `ubichat` 표기 정합화
- 공통 데이터 계약 정리
- 권한·상태·승인 정책 충돌 해소
- 현행 목업과 기획 문서 동기화

## Phase 2 — 핵심 사용자 여정 완성

- 공개 대학 탐색·상세
- 학생 로그인·가입·상담 시작
- 대학 상담 인박스·종료·재문의
- 대학 공개정보 직접 게시
- 어드민 대학 등록 승인·대학계정 발급

## Phase 3 — 콘텐츠·광고 운영

- 콘텐츠 유형·분류·게시 상태
- 콘텐츠 CMS와 공개 콘텐츠 화면
- 광고 구좌·기간·순서·상태 관리
- 광고 노출·클릭 측정

## Phase 4 — 검증·배포

- 데스크톱·모바일 전체 흐름 검수
- `index.html` 정적 배포 진입점 검수
- 접근성·빈 상태·오류 상태 검수
- 데이터 계약 통합
- GitHub·Vercel 배포
- KPI 측정 기반 마련

## 보류

- 학생 유치 홍보 페이지·등록 문의 (D-010, 사용자 재개 지시 대기)
- 실제 개발 일정과 인력 배분
- 결제·광고 과금 방식
- 추천 알고리즘
- 자동 번역
- 고급 상담 자동 배정
