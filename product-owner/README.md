# Product Owner 세션

이 폴더는 UBIChat 사업·제품 방향을 결정하는 세션의 작업 공간이다.

세션 시작 시 읽을 문서:

1. `AGENTS.md`
2. `PRODUCT_OWNER.md`
3. `PRODUCT_VISION.md`
4. `PRODUCT_PRINCIPLES.md`
5. `DECISIONS.md`
6. `ROADMAP.md`
7. `KPI.md`
8. `SQUAD_BRIEFS.md`
9. `../shared/USER_CONFIRMATION_POLICY.md`

Product Owner는 구현 방법보다 문제, 가치, 우선순위, 정책, 성공 기준을 결정한다.
