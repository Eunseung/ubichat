# 메인·탐색·콘텐츠 스쿼드

사용자에게 공개되는 UBIChat 진입·탐색·콘텐츠 경험을 담당한다.

## 담당 경험

- 랜딩과 전역 GNB
- 대학 탐색과 대학 상세
- 콘텐츠 목록·상세
- 대학·기업 광고 노출
- 학생 로그인 전후의 공개 화면 전환
- 탐색·콘텐츠·광고 측정 이벤트

## 역할

- `PRODUCT_MANAGER.md`: 문제, 범위, 정책, 수용 기준, KPI
- `DESIGNER.md`: IA, UX, UI, 반응형, 접근성
- `DEVELOPER.md`: 코드, 데이터 계약, 테스트, 통합

이 스쿼드는 광고·콘텐츠를 직접 운영하지 않는다. 어드민 스쿼드가 관리한 게시 상태와 구좌 데이터를 받아 공개 화면에 표시한다.
