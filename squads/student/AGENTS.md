# 학생 스쿼드 AI 라우터

이 디렉터리에서 작업하는 AI는 학생 스쿼드의 역할과 파일 경계를 따른다.

## 세션 시작 시 필수 순서

1. 이 파일과 `README.md`를 끝까지 읽는다.
2. 사용자의 요청을 아래 유형으로 분류한다.
3. 해당 역할 문서를 작업 전에 반드시 읽는다.
4. 여러 유형이면 `Product Manager → Designer → Developer` 순서로 필요한 문서를 모두 읽는다.
5. 최신 Product Owner 결정과 관련 `shared` 계약이 제공되었는지 확인한다. 없으면 임의로 확정하지 않고 가정·의존성을 기록한다.

## 요청 라우팅

| 요청 유형 | 반드시 읽을 역할 문서 |
|---|---|
| 제품 문제, 사용자 여정, 요구사항, 정책 제안, 범위, 우선순위, 완료 기준 | `PRODUCT_MANAGER.md` |
| UX/UI, 정보 구조, 화면 상태, 문구, 반응형, 접근성, 디자인 검수 | `DESIGNER.md` |
| 코드 구현, 버그 수정, 리팩터링, 데이터 연동, 테스트, 기술 검토 | `DEVELOPER.md` |
| 신규 기능의 기획부터 구현까지 | 세 역할 문서 모두 |
| 사업 방향, KPI, 수익 모델, 스쿼드 간 정책 충돌 | `PRODUCT_MANAGER.md`를 읽고 Product Owner에게 에스컬레이션 |

요청이 모호하면 Product Manager 관점에서 문제와 범위를 먼저 정리한다. 디자인이나 구현을 먼저 확정하지 않는다.

## 파일 권한

학생 스쿼드가 직접 수정할 수 있는 제품 파일:

- `/login.html`
- `/signup.html`
- `/student-desktop.html`
- `/student-mobile.html`
- `/student-session.js`

학생 스쿼드 운영 문서는 `/squads/student/` 아래에서 관리한다.

다음은 직접 수정하지 않는다.

- 공개 대학 탐색·상세와 GNB shell
- 학교·어드민 화면
- 다른 스쿼드 운영 문서
- 승인되지 않은 `shared` 계약

비소유 영역 변경이 필요하면 구현을 멈추지 말고 담당 스쿼드용 인계 요청을 작성한다. 단, 비소유 파일을 대신 수정하지 않는다.

## 공통 실행 규칙

- 기존 코드와 문서를 먼저 확인하고 현재 동작을 근거로 판단한다.
- 사용자 또는 다른 작업자의 미커밋 변경을 보존한다.
- Product Owner 결정을 하위 역할이 덮어쓰지 않는다.
- 정책, 디자인, 구현을 구분하고 결정 근거를 남긴다.
- 데스크톱과 모바일의 기능·상태 차이를 의도 없이 만들지 않는다.
- 로딩, 빈 상태, 오류, 권한 없음, 세션 만료, 완료 상태를 정상 경로와 함께 다룬다.
- 개인정보·인증·상담 기록에 영향을 주는 변경은 보안과 데이터 보존 영향을 명시한다.
- 공통 계약을 추측해 복제하지 않는다. 필요한 필드와 동작을 계약 변경 요청으로 제안한다.

## 역할 간 작업 순서

1. Product Manager가 요구사항과 완료 기준을 확정한다.
2. Designer가 요구사항별 화면 상태와 상호작용을 정의한다.
3. Developer가 구현하고 검증 결과를 남긴다.
4. Product Manager가 완료 기준으로 수용 여부를 판단한다.

단순 오탈자나 명백한 결함은 필요한 최소 역할만 사용할 수 있다. 사용자 가치나 정책이 달라지면 Product Manager 검토로 되돌린다.

## Product Owner에게 즉시 올릴 사안

- 사업 목표, KPI, 수익 모델 또는 로드맵 변경
- 학생·학교·어드민·탐색 스쿼드 사이의 소유권 충돌
- 상담 생성·배정·종료·재개 권한 등 상담 수명주기 정책
- 가입 자격, 역할, 개인정보, 보관·삭제 정책
- 공통 GNB, URL, 데이터 스키마, 분석 이벤트 계약 변경
- 승인된 범위나 우선순위에 중대한 영향을 주는 일정·기술 위험

## 사용자 확인 게이트

`shared/USER_CONFIRMATION_POLICY.md`를 따른다. 상담 수명주기, 학생 권한, 인증, 개인정보, 문서 정책 또는 모호한 요청은 사용자 승인 전 수정·구현하지 않는다. 완료 후 결과 확인도 받는다.
