# 학생 문서 전송 전 미리보기 — 2026-07-29

- 상태: 사용자 승인된 학생 포털 시연 정책
- 역할 협업: PM 정책 → Designer 상태·접근성 → Developer 구현
- 소유 범위: `student-desktop.html` 반응형 화면
- 비소유 범위: 실제 파일 저장·변환·바이러스 검사·학교 인박스·공통 계약

## PM 정책

- 학생이 문서 보관함의 기존 문서를 상담 채널로 전송할 때, 최종 전송 전에 문서명·분류·전송 대상을 확인할 수 있다.
- `전송`을 다시 선택했을 때만 해당 `studentId + universityId + affiliationId` 채널에 전송한다. 취소는 전송하지 않는다.
- 대학이 요청한 기존 문서와 업로드 직후 전달 문서에도 같은 확인 흐름을 적용한다.
- PDF는 학생에게만 시연용 첫 페이지 카드를 보여 준다. 원본 파일을 추가로 복제·색인·분석하지 않는다.
- `기타` HTTPS 클라우드 링크는 외부 파일을 불러오거나 미리보지 않는다. 링크 도메인과 새 창 열기만 제공한다.
- 차단된 채널은 미리보기의 최종 전송을 허용하지 않는다.

## 학교 요청 예시 파일

- 학교는 서류 요청마다 선택 PDF 예시 파일 1개를 제공할 수 있다. 학생은 요청 카드와 요청 문서 선택 화면에서 `제출 예시 보기`로 열람한다.
- 예시 파일은 학생이 보낼 원본 문서와 별개다. 학생 문서 보관함에 저장하거나 상담 채널에 다시 전송하지 않는다.
- 예시가 없는 요청은 버튼을 표시하지 않는다. 링크 만료·권한 오류는 안전한 오류 안내를 보여 준다.
- 시연 화면의 고정 예시는 실제 학교 파일이 아니다. 실서비스는 학교 제공 파일 식별자와 권한 확인된 미리보기 URL이 필요하다.

## Designer 명세

- 문서 선택 뒤 `전송 전 미리보기` 모달을 연다.
- 상단에는 파일명·분류·전송 대상, 본문에는 PDF 첫 페이지 카드 또는 외부 링크 카드, 하단에는 `취소`와 `이 문서 전송`을 둔다.
- PDF 카드에는 `시연용 미리보기`를 분명히 표시한다. 실제 문서값·개인정보를 샘플로 만들어 표시하지 않는다.
- 외부 링크 카드는 도메인과 “플랫폼은 파일을 열람·복제하지 않아요” 안내를 표시한다.
- 작은 화면에서는 모달을 전체 폭으로 사용하고, 긴 파일명·도메인은 줄바꿈한다. 취소 뒤에는 문서 선택 목록으로 돌아간다.
- 모달은 `role="dialog"`, `aria-modal`, 명확한 닫기·전송 레이블과 Escape 닫기를 제공한다.

## 수용 기준

- 일반 문서 선택, 대학 요청의 기존 문서, 업로드 직후 전달 모두 미리보기 후 전송된다.
- 취소·Escape·배경 닫기에서는 채팅 메시지와 요청 완료 상태가 바뀌지 않는다.
- 전송 완료 후 해당 채널에 문서 카드가 1회 표시되고 요청 CTA는 `전송 완료`가 된다.
- 링크 문서는 외부 콘텐츠를 화면 안에 불러오지 않으며 새 창 열기에 `noopener`를 적용한다.
- 문서명·URL·메시지 본문을 분석 이벤트에 추가하지 않는다.
- 학교 요청에 예시가 있으면 동일 소속구분 학생만 예시 파일을 열람한다. 다른 소속구분·차단 채널에는 노출하지 않는다.

## 후속 의존성

- 실서비스 PDF 첫 페이지는 권한 확인된 단기 URL 또는 브라우저 내 로컬 객체 URL이 필요하다.
- 확정 D-009의 “즉시 전송” 문구와 전송 전 확인 단계의 공통 정책 반영 여부는 Product Owner 확인이 필요하다.
- 학교 입력·공통 요청 형식은 [변경 요청](../../shared/change-requests/CR-2026-07-29-document-request-example-file.md)으로 분리했다.
