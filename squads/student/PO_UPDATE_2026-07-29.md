- 상태: 사용자 시연용 구현 반영 · D-015/D-016 정합화 완료 · 공통 계약 연동 대기
- 소유 범위: `student-desktop.html`, `login.html`, `signup.html`, `student-session.js`
- 비소유 파일·공통 계약: 수정 없음

## 반영 내용

### 문서 보관함

- 문서 카테고리: 성적증명서, 어학성적, 졸업(예정)증명서, 여권, 가족관계증명서, 재정증명서, 공증문서, 기타
- 기존 문서의 버전·학교별 전송 이력 표기를 제거하고 `수정` 동작으로 교체
- 플랫폼 파일 업로드: PDF만 허용, 파일당 10MB 이하
- `기타` 카테고리에서만 HTTPS 클라우드 링크를 입력·열 수 있음. Google Drive·Dropbox 예시 제공, 파일은 플랫폼에 복제하지 않음
- `기타`가 아닌 카테고리에서는 링크 입력란을 숨기고 비활성화
- 우측 안내 패널을 삭제하고 문서 목록을 전체 폭으로 확장
- 기존 문서는 전송 전 미리보기에서 파일명·분류·대상을 확인하고 최종 전송한다. PDF는 시연용 첫 페이지 카드, 외부 링크는 도메인 정보만 표시한다.
- 학교 서류 요청에는 선택 예시 파일을 표시할 수 있도록 학생 시연 화면을 보완했다. 학교 입력·실제 파일 권한 URL은 공통 변경 요청으로 분리했다.

### 내 상담·채팅

- 일반 로그인·회원가입 완료 뒤 기본 도착 화면은 `index.html`이다. 대학의 상담 시작하기에서 전달된 `universityId + affiliationId`는 로그인 뒤 선택 상담 채널로 복귀해 웰컴 메시지를 표시한다.
- 로그인 세션에서 `student-desktop.html`을 쿼리 없이 직접 열어도 레거시 대학 탐색 목업을 표시하지 않고 `index.html`로 이동한다. 학생 메뉴의 명시적 `view` 값과 선택 대학·소속구분 상담 문맥만 해당 화면을 연다.
- 메시지·문서 카드가 채팅 영역 밖으로 밀려 잘리지 않도록 대화 영역을 독립 스크롤 구조로 수정
- 한글 IME 조합 중 Enter가 메시지를 분리 전송하지 않도록 처리
- 대학별 시연 대화를 분리
  - 서정대학교: 컴퓨터공학 지원·성적증명서 전송
  - 한양여자대학교: 장학금 문의·담당자 배정 대기
  - 연성대학교: 호텔관광 전공·기숙사 문의·상담 종료
- 학생의 `다시 상담하기`는 기존 대화를 유지한 채 재신청·대기 상태를 추가 표시
- 대학이 종료 채팅을 재개하면 기존 이력 뒤에 별도 시스템 메시지와 재개 시각을 표시하고, 상태를 `진행중`으로 전환해 바로 답장할 수 있게 함
- 구미대학교 학부/학사 채널은 신규 상담 진입 시 학교가 작성한 웰컴 메시지 1건만 표시하고, 학생이 바로 작성할 수 있게 함
- 학생 화면에서 대학 관계자 실명을 제거하고 대학명·상담팀·상담 상태만 표시
- 대학 표시는 공개 탐색 화면의 기본 자산 규칙과 맞춰 이니셜 `GM`·`HY`·`YS` 사용
- 대학 요청 문서 시연: 등록된 어학성적과 업로드한 여권을 전송 전 미리보기에서 확인한 뒤 해당 채널로 전송
- 최초 상담이 시작된 소속구분 채널은 학생의 첫 메시지 전에 대학 웰컴 메시지를 1회 표시한다. 팀 발신·시간·작성 가능한 입력창을 함께 제공한다.

### D-023 학생 표시 매핑

- 학생 화면에서는 내부 분류값 `apostille`을 유지하며 `공증문서`로만 표시한다.

### D-015·D-016 소속구분별 상담 채널

- 채널·상태 식별자는 프로토타입에서 `studentId + universityId + affiliationId` 단위로 취급
- 구미대학교의 학부/학사, 언어교육원, 대학원을 별도 목록·별도 이력으로 표시
- 대학원 채널의 상담 제한은 같은 대학의 학부/학사·언어교육원 채널에 영향을 주지 않음
- `universityId`와 `affiliationId`를 공개 상세→로그인→회원가입→학생 포털 URL에 보존
- 식별자가 없거나 알 수 없는 소속구분은 새 채널을 추정·생성하지 않고 안내 후 기존 목록으로 이동

### 반응형·접근성

- 학생 포털의 데스크톱·태블릿·모바일 레이아웃을 보완
- 긴 메시지·문서명은 줄바꿈하며, 문서 링크 입력란은 비노출 상태에서 포커스·입력이 불가함

## PO 확인 요청

1. **상담 재개 정책**: 현재는 시연용으로 종료된 연성대학교 국제교류 채널에 이전 이력을 유지한 재신청·대기 상태를 표시한다. 실제 서비스의 재개 권한, 새 회차 생성 여부, 학교 알림·배정 규칙, 감사 이력은 공통 상담 수명주기 정책·계약 확정이 필요하다.
2. **대학 관계자 이름 노출 정책**: 학생 화면에서는 개인 실명 대신 대학명·상담팀만 표시한다. 학생·학교 화면 전체에 적용할 개인정보·표시 원칙인지 확인이 필요하다.
3. **외부 링크 접근 실패 상태**: D-009의 링크 등록·열기까지는 반영했으며, 실제 서버 연동 시 링크 만료·권한 없음·서비스 장애 안내와 학교 측 열람 정책이 필요하다.
4. **학교 요청 예시 파일**: 학교가 선택 PDF 예시를 붙일 수 있도록 공통 요청 형식 확장이 필요하다. [CR-2026-07-29-document-request-example-file](../../shared/change-requests/CR-2026-07-29-document-request-example-file.md)에 학생 표시·학교 입력·권한 URL 요구사항을 기록했다.
