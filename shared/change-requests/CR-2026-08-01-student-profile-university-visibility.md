# CR-2026-08-01 — 대학 상담 학생 프로필 표시 최소화

- 요청 스쿼드: Product Owner
- 담당 Owner: 학생 PM·학교 PM
- 필수 검토자: 학생 Developer·학교 Developer
- 근거: D-028, 사용자 직접 지시 (2026-08-01)
- 대상: `signup.html`, `student-desktop.html`, `student-mobile.html`, `university-admin.html`, 향후 `consultation-documents` 계약
- 문제: 표준 회원가입이 수집·저장하지 않는 희망 전공·입학 시기가 대학 화면의 고정 목업값으로 표시된다. 도시·사용 언어도 상담 목록·학생 정보·프로필 전달 메시지에 노출된다.
- 변경:
  1. 대학 상담 화면은 도시·사용 언어를 표시·전달하지 않고 국적만 표시한다.
  2. 희망 전공·입학 시기 고정 데이터와 표시를 학생·학교 목업에서 제거한다.
  3. 도시 입력은 학생 가입 화면에 남을 수 있으나 대학 상담 기본 프로필로 전달·표시하지 않는다.
- 호환성: 학생이 채팅 본문에서 직접 공유한 전공·입학 계획은 메시지 원문으로 유지한다. 이는 프로필 필드가 아니다.
- 검증: 모든 상담 목록, 우측 학생 정보, 프로필 전달 시스템 메시지에서 제외 항목 0건. 표준 회원가입 후 대학 화면에 수집하지 않은 전공·입학 시기 값 0건.
