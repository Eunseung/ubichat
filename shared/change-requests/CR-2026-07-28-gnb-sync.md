# CR-2026-07-28 — 공개·학생 인증 GNB 동기화

- 요청 ID: CR-2026-07-28-gnb-sync
- 날짜: 2026-07-28
- 요청 스쿼드: 메인·탐색·콘텐츠
- 담당 역할: PM·Designer·Developer
- 대상 파일·계약: `landing.css`, 공개 페이지 GNB, `student-desktop.html`, `shared/contracts/navigation-auth.md`
- 문제: 공개 화면과 학생 인증 화면의 GNB 항목이 달라 `콘텐츠` 진입점이 누락되고, 인증 뒤 `대학 서비스`·`로그인` 버튼이 CSS 표시 규칙에 의해 보인다.
- 제안 변경: 모든 공개 GNB와 학생 인증 GNB를 `대학 탐색 / 내 상담 / 콘텐츠 / 학생 프로필` 구조로 맞춘다. 비로그인 상태는 `내 상담`을 `상담하기`로 표시하고 `대학 서비스 / 로그인`을 제공한다. `[hidden]` 상태는 버튼 스타일보다 우선한다.
- 변경하지 않을 범위: 학생 포털의 상담·문서·프로필 화면과 학생 인증 저장 방식, 콘텐츠 게시 상태 계약
- 영향받는 스쿼드: 학생, 메인·탐색·콘텐츠
- 호환성 위험: `student-desktop.html`의 GNB 항목 수 증가로 작은 화면에서 줄바꿈 또는 가로 스크롤 가능
- 마이그레이션: 없음
- 검증 방법: 로그인 학생·비로그인 학생 상태에서 공개 헤더의 버튼 표시와 학생 포털의 `콘텐츠` 링크를 데스크톱·모바일에서 확인
