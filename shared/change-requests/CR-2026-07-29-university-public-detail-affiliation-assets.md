## PO 결정 반영 — D-013

1. 탐색 카드의 단위는 `universityId + affiliationId`다. 공개 소속구분마다 카드 1개를 만들며, 카드명은 소속구분 공개 표시명을 사용한다. 카드의 상세 URL·상태에는 선택 `affiliationId`를 명시한다.
2. 대학과 소속구분이 모두 `published`일 때만 해당 카드를 공개한다.
3. 상세는 선택 소속구분의 공개 정보와 자산을 표시한다. 자산·필드가 없으면 안전한 기본·빈 상태를 표시한다. 대학 단위 자산 자동 복제·보정은 하지 않는다.
4. 웰컴 메시지·이미지는 상담 시작 시점의 채팅 기능으로 유지하며, 공개 상세에는 포함하지 않는다.
5. 상담 CTA는 `studentId + universityId + affiliationId` 독립 상담 채널로 연결하고 선택 `affiliationId`를 유지한다. 대학 운영 화면은 하나로 유지한다.
