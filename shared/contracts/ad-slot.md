# Ad Slot Contract

## 목적

어드민이 운영하는 대학·기업 광고 구좌를 메인이 일관되게 표시한다.

## Steward와 소비자

- Steward: 어드민 Developer
- 사업 정책 승인: Product Owner
- 공개 렌더링·이벤트: 메인

## 현재 필드

```text
AdSlot
├─ id
├─ advertiser
├─ label
├─ asset
├─ status
├─ category
└─ template
```

## 현재 상태

- `active`: 공개 렌더링 가능
- `inactive`: 공개 화면 미노출

## 구좌 유형

- `university`: 대학 고객사 광고
- `corporate`: 금융·주거·통신 등 기업 광고

## 책임

- 어드민: 생성, 수정, 활성 상태, 광고주·소재 정보
- 메인: 활성 구좌 렌더링, 광고 표기, 노출·클릭 이벤트
- Product Owner: 유료 노출 원칙, 우선순위, 카테고리 정책

## 불변 조건

- 비활성 구좌는 공개 화면에 표시하지 않는다.
- 대학 광고와 일반 대학 결과를 구분한다.
- 기업 광고와 일반 콘텐츠를 구분한다.
- 이미지 대체 텍스트를 제공한다.
- 구좌 데이터가 불완전하면 숨기거나 안전한 대체 화면을 사용한다.

## 구체화 필요 필드

아래는 Product Owner 결정 후 추가한다.

- 노출 시작·종료 시각
- 노출 순서
- 목적지 URL
- 광고 표기 문구
- 타깃 조건
- 캠페인·측정 ID
