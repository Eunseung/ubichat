# Navigation and Authentication Contract

## 목적

메인의 GNB와 학생 인증·개인 기능을 일관되게 연결한다.

## GNB

### 비로그인

- UBIChat 로고 → `index.html`
- 대학 탐색
- 상담하기
- 콘텐츠
- FAQ
- 공지사항
- 학교 서비스
- 로그인/회원가입

### 학생 로그인

- UBIChat 로고 → `index.html`
- 대학 탐색
- 내 상담
- 콘텐츠
- FAQ
- 공지사항
- 언어 선택
- 학교 서비스 숨김
- 학생 프로필 메뉴
- 학생 로그인 버튼 숨김
- 데스크톱: GNB와 프로필 메뉴를 분리한다. 프로필 메뉴는 학생 이름·이메일, `문서 보관함·마이페이지·로그아웃`만 제공한다.
- 모바일: 햄버거 메뉴 하나에 `대학 탐색·내 상담·콘텐츠·FAQ·공지사항`, 학생 프로필 요약, `문서 보관함·마이페이지·로그아웃`, 언어 선택을 함께 표시한다.

## 소유권

- GNB 구조·표현: 메인
- 학생 인증 상태: 학생
- `내 상담` 화면: 학생
- 대학 서비스 목적지: 학교
- 플랫폼 관리자 진입: 어드민

## 인증 상태 인터페이스

학생 스쿼드는 다음 상태를 제공한다.

- 로그인 여부
- 학생 프로필 표시 정보
- 로그인·로그아웃 이벤트
- 인증 뒤 반환 경로
- 공지사항 로그인 반환 경로
- 상담하려던 대학·소속구분 ID (`universityId`, `affiliationId`)

메인은 인증 상태를 표시 목적으로 소비하며 직접 변조하지 않는다.

## 불변 조건

- 대학·콘텐츠 탐색은 인증 없이 가능하다.
- FAQ는 인증 없이 가능하다.
- 공지사항 GNB 진입은 누구나 가능하지만, 공지 본문은 로그인한 대상 사용자만 볼 수 있다. 비로그인 사용자는 로그인 후 학생 대상 공지 화면으로 반환한다.
- 상담 시작과 개인 기능은 학생 인증이 필요하다.
- 로그인 전 선택한 대학·소속구분(`universityId`, `affiliationId`)과 반환 경로를 유지한다.
- 학생 로그인 상태에서는 학교 서비스를 숨긴다. 로그아웃하면 다시 표시한다.
- 모바일 학생 프로필 메뉴와 다국어 선택은 햄버거 밖에 중복 표시하지 않는다.
- `내 상담·공지사항`은 데스크톱 GNB와 모바일 햄버거의 페이지 메뉴에만 둔다. 학생 프로필 메뉴에 중복하지 않는다.
- 대학 계정과 학생 계정의 진입을 섞지 않는다.
