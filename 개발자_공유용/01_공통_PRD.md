# UBIChat 공통 PRD

## 1. 제품 정의

UBIChat은 해외 학생이 한국 전문대학과 공개 소속구분을 탐색하고, 해당 소속구분 담당자와 직접 상담하며, 요청 문서를 안전하게 전달하는 서비스다.

## 2. 핵심 사용자

- 학생: 대학 탐색, 상담, 문서 전달, 개인 정보 관리
- 학교 구성원: 공개정보 게시, 상담 운영, 문서 요청, 멤버 관리
- 플랫폼 관리자: 대학 등록 승인, 대학계정 발급·상태 관리, 공지·콘텐츠·광고 운영

## 3. 제품 목표

1. 로그인 전 대학·콘텐츠 탐색을 제공한다.
2. 상담 시작 시점에 학생 인증을 요구한다.
3. 대학과 소속구분을 명확히 구분한다.
4. 학생·대학·소속구분별 상담 이력을 독립적으로 유지한다.
5. 학교가 배정 소속구분의 공개정보를 직접 게시한다.
6. 학생이 확인한 문서만 대학에 전달한다.
7. 정적 HTML 프로토타입을 `index.html`에서 일관되게 시연한다.

## 4. 핵심 요구사항

### 공개 서비스

- 메인 상단에 대학명·지역·분야 검색창을 제공한다.
- 대학 목록·상세·콘텐츠·FAQ는 로그인 없이 열람할 수 있다.
- 대학 탐색 카드는 `대학 + 공개 소속구분` 단위다.
- 카드와 상세 URL은 `universityId + affiliationId`를 유지한다.
- 프로토타입의 현재 대학은 모두 공개한다.
- 공개 소속구분 더미가 없는 대학은 `undergraduate` 기본 카드를 사용한다.
- 구미대학교는 학부/학사·언어교육원·대학원 카드를 별도로 제공한다.

### 학생

- 로그인 학생은 소속구분별 독립 상담 목록과 이력을 본다.
- 최초 상담에는 대학의 웰컴 메시지를 표시한다.
- 문서 분류의 사용자 표기는 `공증문서`를 사용한다. 기존 내부 값 `apostille`은 호환을 위해 유지할 수 있다.
- 모든 문서 전송은 미리보기와 `이 문서 전송` 확인 뒤 완료한다.
- 요청 문서가 문서 보관함에 있으면 선택해 보낸다. 없으면 PDF를 업로드해 보낸다.
- 학교 재요청 시 업로드 상자와 기존 문서 선택을 다시 제공한다.

### 학교

- 대학 운영 화면은 대학·소속구분별 별도 페이지로 나누지 않고 기존 단일 운영 화면을 유지한다.
- 학교 구성원은 자기 배정 소속구분의 공개정보와 자산을 직접 게시한다.
- `입학 안내 자료`는 PDF만 허용한다.
- 공개 상세 탭은 추가·수정·활성·비활성·순서 변경을 지원한다.
- 기본 탭은 `상세 소개·학과 정보·지원 과정·기숙사`다.
- `기숙사` 탭은 본문과 사진을 함께 관리하며 공개 상세에서 사진 캐러셀을 제공한다.
- 종료된 상담은 학교가 다시 시작할 수 있다.
- 차단·차단 해제는 배정 소속구분 범위에서 수행한다.

### 플랫폼 어드민

- 대학 등록 신청을 승인·보완·반려한다.
- 최고관리자·소속구분 관리자·멤버 계정을 발급할 수 있다.
- 대학 공개정보·로고·배경·사진·브로셔를 승인하지 않는다.
- 학생·학교 대상 플랫폼 공지를 작성·게시·종료한다.
- 콘텐츠 CMS와 광고 구좌를 운영한다.
- 학생 문서 원본과 상담 원문을 열람하지 않는다.

## 5. GNB 기준

### 비로그인

`대학 탐색 · 상담하기 · 콘텐츠 · FAQ · 공지사항 · 학교 서비스 · 로그인/회원가입`

### 로그인 학생 데스크톱

`대학 탐색 · 내 상담 · 콘텐츠 · FAQ · 공지사항 · 언어 선택 · 프로필`

- `학교 서비스`, `로그인/회원가입`은 숨긴다.
- 프로필 메뉴는 이름·이메일, `문서 보관함·마이페이지·로그아웃`만 제공한다.

### 로그인 학생 모바일

햄버거 하나에 다음 순서를 제공한다.

1. 대학 탐색·내 상담·콘텐츠·FAQ·공지사항
2. 학생 이름·이메일
3. 문서 보관함·마이페이지·로그아웃
4. 언어 선택

## 6. 비범위

- 별도 학생 유치 홍보 페이지
- 구미대학교 운영관리와 공개 상세의 실시간 저장소 동기화
- 실제 백엔드·DB·파일 저장소·바이러스 검사
- 실제 이메일 인증·권한 API
- 다중 브라우저·다중 기기 실시간 동기화
- 결제·광고 과금·자동 번역·추천 알고리즘

## 7. 핵심 KPI

- 대학 탐색 진입률
- 대학 상세 전환율
- 상세에서 상담 시작 클릭률
- 로그인·가입 완료율
- 상담 신청 완료율
- 중앙값 첫 응답 시간
- 문서 요청·재요청 전달 성공률
- 공개정보 게시 완료율
- 종료 상담 재개 후 학생 응답률
- 로그인 상태별 잘못된 GNB 노출 건수
- 권한·차단·공지 대상 오류 건수

## 8. 공통 완료 조건

- 요구사항과 수용 기준 충족
- 소유 파일 경계 준수
- `studentId + universityId + affiliationId` 맥락 유지
- 데스크톱·모바일 검증
- 로그인·로그아웃 검증
- 빈 상태·오류·권한 상태 검증
- 로컬 링크와 JavaScript 문법 검증
- 기존 사용자 변경사항 보존
