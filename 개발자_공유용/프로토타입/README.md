# UBIChat 정적 프로토타입

공유용 실행 코드다. 이 폴더를 정적 서버의 루트로 열어 `index.html`부터 확인한다.

## 포함 범위

- 공개·학생·학교·어드민 HTML
- JavaScript, CSS, 배너·구미대학교 자산
- 고정 더미 대학 공개정보

## 제외 범위

- 학교 운영 화면과 공개 상세의 브라우저 저장소 실시간 동기화
- 실제 백엔드, DB, 파일 저장, 인증 API

## 실행

정적 서버로 실행한다. `file://` 직접 실행은 브라우저 저장소와 일부 모듈 동작이 다를 수 있다.

```sh
npx serve .
```

배포 메인은 `index.html`이다.
