# UBIChat 회원·권한 정책

## 1. 역할

| 역할 | 수량·배정 | 업무 범위 |
|---|---|---|
| 학생 | 개인 계정 | 자기 상담·문서·프로필 |
| 대학 최고관리자 | 대학당 정확히 1명 | 대학 전체·모든 소속구분 |
| 소속구분 관리자 | 복수 가능 | 배정된 하나 이상의 소속구분 |
| 대학 멤버 | 복수 가능 | 배정된 하나 이상의 소속구분 |
| 플랫폼 어드민 | 운영 조직 정책 | 대학 등록·계정·공지·콘텐츠·광고 운영 |

한 사용자가 학부/학사와 언어교육원 등 여러 소속구분을 동시에 담당할 수 있다. 한 소속구분에도 복수 관리자와 복수 멤버를 둘 수 있다.

## 2. 대학계정 발급

| 발급 대상 | 플랫폼 어드민 | 대학 최고관리자 | 소속구분 관리자 |
|---|---:|---:|---:|
| 대학 최고관리자 | 가능 | 불가 | 불가 |
| 소속구분 관리자 | 가능 | 가능 | 불가 |
| 대학 멤버 | 가능 | 가능 | 자기 배정 소속구분에 가능 |

- 최초 최고관리자는 운영사가 별도 발급하거나 대학 등록 승인 과정에서 발급한다.
- 소속구분 관리자는 운영사 또는 최고관리자가 발급한다.
- 멤버는 운영사, 최고관리자 또는 해당 소속구분 관리자가 발급한다.

## 3. 공개정보·자산 권한

| 작업 | 최고관리자 | 소속구분 관리자 | 멤버 | 플랫폼 어드민 |
|---|---:|---:|---:|---:|
| 공개정보 작성·수정 | 전체 가능 | 배정 범위 가능 | 배정 범위 가능 | 불가 |
| 로고·배경·사진·브로셔 등록 | 전체 가능 | 배정 범위 가능 | 배정 범위 가능 | 불가 |
| 직접 게시·숨김 | 전체 가능 | 배정 범위 가능 | 배정 범위 가능 | 불가 |
| 대학 등록 승인 | 불가 | 불가 | 불가 | 가능 |
| 공개정보 사전 승인 | 불필요 | 불필요 | 불필요 | 권한 없음 |

대학 등록 승인과 공개정보 게시는 별도 업무다. 플랫폼 어드민은 학교가 게시한 공개정보·자산을 사전 승인하지 않는다.

## 4. 상담 열람·응대

- 상담 채널 단위는 `studentId + universityId + affiliationId`다.
- 학생은 같은 대학의 학부·언어교육원·대학원 상담을 별도 항목으로 본다.
- 학교 구성원은 자기 배정 소속구분 상담만 열람·응대한다.
- 여러 소속구분에 배정된 구성원은 해당 채널들을 모두 볼 수 있다.
- 대학 운영 화면은 하나이며 권한에 따라 보이는 소속구분과 상담만 달라진다.
- 상담 원문은 플랫폼 어드민 일반 운영 화면에 제공하지 않는다.

## 5. 상담 차단·해제·재개

- 최고관리자·소속구분 관리자·멤버 모두 배정 범위에서 차단할 수 있다.
- 차단 범위는 해당 `studentId + universityId + affiliationId` 채널이다.
- 다른 소속구분 상담에는 영향을 주지 않는다.
- 차단된 학생은 해당 소속구분에 재상담할 수 없다.
- 차단 해제 시 해제 사유가 필수다.
- 종료 상담은 학교가 다시 시작할 수 있으며 학생에게 재개 시스템 메시지를 남긴다.

## 6. 학생 문서

- 학교가 문서를 요청했다는 사실만으로 학생 문서를 열람할 수 없다.
- 학생이 명시적으로 전송한 문서만 해당 상담 채널의 학교 관계자가 볼 수 있다.
- 등록 문서가 있으면 기존 문서를 선택한다. 없으면 새 PDF를 업로드한다.
- 모든 전송은 미리보기와 `이 문서 전송` 확인이 필요하다.
- 취소·닫기는 전송으로 처리하지 않는다.
- 학교의 재요청은 기존 수신 문서를 자동 대체하지 않는다. 학생 재전송 뒤 새 버전을 `업데이트됨`으로 표시한다.
- 요청 예시 파일은 플랫폼 운영측이 관리한다. 학교가 학생 문서함에 직접 저장하지 않는다.
- 학생 문서 원본·메시지 본문·예시 파일 URL을 분석 이벤트나 일반 활동 이력에 넣지 않는다.

## 7. 공지 권한

- 플랫폼 어드민만 공지를 작성·수정·게시·종료한다.
- 대학 구성원은 플랫폼 공지를 작성할 수 없다.
- 학생은 GNB·모바일 햄버거의 `공지사항`에서 자기 대상 공지를 읽는다.
- 학교 구성원은 학교 홈 공지 위젯과 `전체 보기`에서 자기 대상 공지를 읽는다.

## 8. 활동 이력

- 계정·대학 등록·콘텐츠·광고·공지·차단·해제 같은 운영 변경의 처리자, 시각, 대상, 작업, 사유를 기록할 수 있다.
- 학생 상담 원문과 문서 원본은 기록하지 않는다.
- 활동 이력은 학생 문서 열람 권한을 만들지 않는다.
