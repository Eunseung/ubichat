# 메인·탐색·콘텐츠 스쿼드 개발 브리프

- 우선순위: P1
- 소유 경험: 랜딩, 공통 GNB, 대학 탐색·상세, 콘텐츠, FAQ, 광고 노출
- 주요 소유 파일: `index.html`, `landing.css`, `landing.js`, `public-navigation.js`, `university-explore.*`, `university-detail.*`, `university-public-prototype.js`, `content.html`, `faq.*`

## 구현 요구사항

1. `index.html`을 정적 배포 메인으로 유지한다.
2. 모든 공개·학생 헤더의 UBIChat 로고를 `index.html`로 연결한다.
3. 비로그인 GNB를 `대학 탐색·상담하기·콘텐츠·FAQ·공지사항·학교 서비스·로그인/회원가입` 기준으로 맞춘다.
4. 로그인 학생 GNB를 `대학 탐색·내 상담·콘텐츠·FAQ·공지사항` 기준으로 맞춘다.
5. 로그인 학생 프로필 메뉴에는 `문서 보관함·마이페이지·로그아웃`만 둔다.
6. 모바일 햄버거는 페이지 메뉴·프로필 요약·개인 메뉴·언어 선택 순서를 유지한다.
7. 랜딩 검색어를 `university-explore.html?q={query}`로 전달한다.
8. FAQ 미리보기를 TOPIK 영역 위에 제공하고 전체 FAQ 페이지와 같은 데이터를 사용한다.
9. 대학 카드는 `universityId + affiliationId` 단위로 렌더링한다.
10. 프로토타입의 현재 대학을 모두 공개한다. 구미대학교는 3개 소속구분 카드를 유지한다.
11. 공개 상세는 선택된 소속구분의 활성 탭·자산·상담 상태만 표시한다.
12. 기숙사 탭 본문 뒤 사진 캐러셀을 제공한다.
13. 공식 홈페이지 버튼은 대학명 헤더 우측, 주소·Google 지도는 상세 정보 영역에 표시한다.
14. 구미대학교는 고정 fixture를 사용한다. 학교 화면 저장소를 읽지 않는다.

## 비범위

- 대학 공개정보 작성·게시 UI
- 학생 상담·문서 본문 구현
- 플랫폼 공지 작성
- 학생 유치용 별도 홍보 페이지
- 학교 운영 화면과 공개 화면 실시간 동기화

## 수용 기준

- 로그인 상태별 GNB 중복·누락이 없다.
- 프로필 메뉴에 `내 상담·공지사항`이 없다.
- 모바일에서 프로필·언어 버튼이 햄버거 밖에 중복되지 않는다.
- 검색어, `universityId`, `affiliationId`, 로그인 반환 경로가 유지된다.
- 공개 카드에서 선택한 소속구분과 상세 내용이 일치한다.
- 자산 없음·탭 없음·상담 중지 상태에서 화면이 깨지지 않는다.
- 로컬 링크, JavaScript 문법, 데스크톱·모바일을 검증한다.
