# UBIChat 개발자 공유 패키지

- 기준일: 2026-07-31
- 목적: 현재 확정된 제품 정책을 개발자가 한 폴더에서 확인하도록 제공한다.
- 적용 대상: 메인·탐색·콘텐츠, 학생, 학교, 어드민 스쿼드
- 구현 형태: 정적 HTML 프로토타입

## 읽는 순서

1. `01_공통_PRD.md`
2. `02_공통_IA_플로우.md`
3. `03_회원_권한_정책.md`
4. `04_공통_데이터_계약.md`
5. 자기 스쿼드의 `스쿼드별_개발_브리프/*.md`
6. `프로토타입/README.md`와 자기 소유 HTML·JS

## 이 패키지의 기준

- 이 폴더는 개발자 전달용 최신 실행본이다.
- 기존 프로젝트 문서는 삭제하거나 수정하지 않았다. 내용이 충돌하면 이 패키지 기준으로 구현하고 Product Owner에게 보고한다.
- 서비스 공식 표기는 `UBIChat`이다. 기존 `unichat` 저장소 키·이벤트·파일명은 호환 식별자일 때만 유지한다.
- 정적 배포 메인은 `index.html`이다. 모든 사용자 화면의 UBIChat 로고는 `index.html`로 이동한다.
- 구미대학교 공개정보는 고정 더미 데이터로 제공한다. 학교 운영 화면과 공개 화면의 브라우저 저장소 실시간 동기화는 개발 범위에서 제외한다.
- 학생 유치용 별도 홍보 페이지와 `등록 문의` 흐름은 보류다.
- 백엔드, 실제 파일 저장, 서버 권한 검증, 다중 기기 실시간 동기화는 이번 범위가 아니다.

## 공통 작업 규칙

- 현재 코드를 먼저 확인하고 이미 완료된 동작은 다시 만들지 않는다.
- 담당 스쿼드 소유 파일만 수정한다. 공통 계약 변경은 영향 스쿼드와 Product Owner 확인을 받는다.
- 권한·개인정보·공개·상담 상태의 의미를 임의 변경하지 않는다.
- 데스크톱·모바일, 로그인·비로그인, 빈 상태·오류 상태를 함께 확인한다.
- JavaScript 문법, 로컬 링크, 쿼리 파라미터, 정적 배포 진입점을 검증한다.
